# 🌿 Plant Exploring

A modern and responsive **Plant Exploring Website** designed for discovering different types of plants and exploring useful information about nature and plants through a clean and engaging user interface.

The project focuses on creating a simple, visually appealing, and user-friendly experience for plant lovers and anyone interested in exploring the plant world.

---

## ✨ Features

* 🌱 Explore different types of plants
* 🔍 Discover plant information
* 🌿 Plant details and descriptions
* 🖼️ Plant images and visual information
* 📚 Organized plant categories
* 📱 Fully responsive design
* 🎨 Clean and modern user interface
* 🧩 Reusable components
* ⚡ Fast and smooth user experience
* 🌳 Nature-focused visual design

## 💻 Run Locally

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd plant-exploring
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The project will normally run at:

```text
http://localhost:5173
```

---

## 🚀 Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
